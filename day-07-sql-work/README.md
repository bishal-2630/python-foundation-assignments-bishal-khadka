Day 07 – SQL Assignment

# Topics Covered

During Day 7, I practiced more advanced SQL concepts using a banking dataset containing customers, accounts, and transactions.

The main concepts covered include:
Joining multiple tables using INNER JOIN, LEFT JOIN, and FULL OUTER JOIN
Finding unmatched customers and orphaned accounts
Using aggregate functions such as SUM, AVG, and COUNT
Using GROUP BY, HAVING, and ORDER BY
Working with subqueries
Using CASE statements for conditional results

# Exercises

The banking_practice.sql file contains SQL exercises based on banking data.
The exercises include:

Finding active accounts with customer details
Finding customers without accounts
Identifying orphaned accounts
Joining customers, accounts, and transactions
Calculating branch-wise balances
Finding top branches by balance
Analyzing account types and customer accounts
Working with transaction totals and average balances

# How to Run

Open the SQL script in DBeaver and execute the queries against the PostgreSQL database containing the banking tables.

You can execute individual exercises one at a time.
