# Day 1: Python Foundations

## Topics Covered

During Day 1, I learned the fundamental concepts of Python programming, including:

- Variables
- Data Types
- String Methods
- Operators
- Conditional Statements (`if`, `elif`, `else`)
- Ternary Expressions
- Type Conversion
- User Input
- Basic Problem Solving

## Exercises

1. Sales Summary
2. Data Quality Checker
3. File Validator
4. Customer Record Cleaner
5. Pipeline Health Status
6. Dataset Access Decision

## How to Run

Run any exercise using the following command:

```bash
python exercise-01-sales-summary.py
```

For example:

```bash
python exercise-02-data-quality-checker.py
python exercise-03-file-validator.py
python exercise-04-customer-record-cleaner.py
python exercise-05-pipeline-health-status.py
python exercise-06-dataset-access-decision.py
```

## What I Learned

Through these exercises, I gained a solid understanding of Python fundamentals such as variables, data types, string manipulation, operators, and conditional statements. I also learned how to use built-in string methods like `strip()`, `lower()`, `upper()`, and `title()`, perform calculations, take user input, and make decisions using `if-elif-else` statements and ternary expressions. These concepts form the foundation for solving real-world programming problems.

## Challenges Faced

One challenge I encountered was understanding when to use `if`, `elif`, and multiple `if` statements. Initially, I expected all matching conditions to execute, but I learned that `elif` stops checking once a previous condition is true. I also spent time understanding different string methods, especially the difference between `capitalize()` and `title()`, and how they affect text formatting. Practicing these exercises helped me understand these concepts more clearly.
